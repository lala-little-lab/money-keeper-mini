# Money Keeper Mini — 開発確認版（実データ入力はまだ禁止）

元のテスト版からの独立コピー。記録・履歴・集計を表示し、その他の画面は内部依存のためコードとDOMが残っています。

## 今回の更新（保存安全性の改善）
- 保存の200ms待機を廃止し、変更ごとに即時暗号化保存を開始。画面上に「保存中／保存済み／保存失敗」を表示。
- 保存処理が残る間のページ離脱にはブラウザ標準の確認を試みます（スマホでは必ず表示されるとは限りません）。
- バックアップ復元時、記録ID重複、日付、種別、金額、イベント等の基本構造を検証してから置換。
- 保存失敗時は以後の自動保存を停止して警告します。

## 前回の更新
- 特別費イベント「NZ旅行」を初期登録。記録画面で選択した支出の `eventTag` に `NZ旅行` が保存される既存処理を利用。
- 暗号化バックアップの書き出しと、ファイル＋作成時パスワードによる復元（全置換）を追加。
- 復元前に暗号化ファイルを復号・最低限の構造確認を行い、確認後に保存して再読み込みします。

## 注意事項
- IndexedDB `money-keeper-mini-encrypted-v1`、PBKDF2(SHA-256、310,000回) + AES-GCM、12文字以上のパスワード。
- **現段階では実際の家計情報を入力しないでください。** 実機の記録・編集・保存・復元、異常系、セキュリティ監査は未完了です。
- **正式版への記録データのインポートは未実装**。記録の完全移行は現時点で保証できません。
- バックアップ復元は現在のMiniの全データを置換します。必ず先にバックアップを保存してください。
- 復元ファイルは作成時のパスワードで復号し、現在のMiniの鍵で再暗号化して保存します。
- GitHubに実データやバックアップをアップロードしないでください。
