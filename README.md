## mini 04：特別費を本体#85の仕様へ（2026-10-26）

- 対象ZIP：`MK_mini_04.zip`。基準：mini 03。参照：本体テスト版 #85（参照のみ）。
- 承認：04の具体的な操作・保存への影響を提示後、ユーザーの「作成してください。」により実装。
- 登録・編集画面、カテゴリ選択と予算、使用・残り・超過表示、全記録一覧とカテゴリ絞り込み、期間中提案・ON/OFF・固定を#85に合わせた。
- カテゴリは複数選択でき、予算なしでも登録可能。予算クリアは未設定、0は0円の設定として区別する。選択解除ではそのカテゴリの予算設定も外す。記録自体は削除しない。
- 編集は対象イベントの位置にフォームを表示。変更を保存／キャンセルでカードに戻る。イベント名変更時は既存記録の名称も変更するか確認する。
- 特別費の使用額は#85と同じく `baseSpent + eventTagが一致する記録のamount合計`。カテゴリ別は該当記録のamount合計。立替は自分の分。手数料・ポイント・割引を新たにこの計算へ加減する変更はない。
- 総予算0／空欄は従来どおり総予算なし。カテゴリ別の0円とは扱いが異なる。
- 日付が開始日〜終了日内（両端含む）の非アーカイブイベントを提案する。対象は支出・立て替えた・立て替えてもらった。期間未設定／期間外でも任意項目から手動選択できる。
- 提案のON/OFFは今回の記録のeventTagを切り替える。複数の期間が重なっても1記録に選べるイベントは1件。固定なしの1件該当で自動ONにする旧miniの処理は廃止。
- 「ONで固定」は次の記録・起動時の既定選択を設定する。押しただけで現在のON/OFFは変更しない。今回だけOFFにできる。固定が複数あると、期間内のイベント配列順で最初の1件を既定にする（#85と同じ）。日付変更は期間外の選択を解除し、固定の既定適用は次の記録・起動時に行う。
- 固定設定は `mkEventFixed:{イベントID:boolean}`。#85の別localStorage保存と異なり、miniでは暗号化保存・バックアップへ含める。画面の開閉・一覧フィルタは保存対象外。
- 暗号化前の業務データを `miniSchemaVersion:3` に更新。旧版1/2は固定設定を空で補完、イベントのselectedCats欠損を既存catBudgetsのキーから補完。既存の記録・イベントID/名称/予算・メモ候補・残高は保持。新規イベント／候補の固定初期登録は行わない。
- 新規版の固定設定欠損・boolean以外、selectedCatsの不正型、未来版を拒否する。暗号化方式・DB名・外側バックアップversion:1は維持。storage.jsとmini-backup.jsは03と同一。
- 03以前のアプリは業務データ版3を読み込めず、安全のため保存停止する。04適用前の暗号化バックアップと旧アプリを保管する。新版データを旧アプリで扱う互換性は提供しない。
- 03のNZ旅行自動登録廃止を維持。保存済みNZ旅行や削除済み名称も勝手に削除しない。イベント削除は従来どおりアーカイブ後の明示操作で、紐づく記録を保持。
- 工程③（記録のメモ候補選択・イベント名のメモ挿入・クリア／復元）、④（本体バックアップのメモ候補だけ取り込み）は未実装。各工程の具体的提案・承認後に進める。
